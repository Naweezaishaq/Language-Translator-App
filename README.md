# CodeAlpha Language Translator

A simple web-based Language Translation Tool built during my AI Internship at CodeAlpha.

## What it does

This tool allows users to:
- Enter text in a text box
- Select a source and target language from dropdown menus
- Click "Translate" to get an instant translation

## Technologies Used

- **HTML** – for building the user interface
- **CSS** – for styling and layout
- **JavaScript** – for handling button clicks and connecting to the API
- **MyMemory Translation API** – to perform the actual translation

## How it works

1. User types text and selects languages
2. JavaScript sends the text to the translation API using `fetch()`
3. The API returns the translated text
4. The translated text is displayed on the screen

## How to run it

1. Download or clone this repository
2. Open the `index.html` file in any web browser
3. Start translating!
